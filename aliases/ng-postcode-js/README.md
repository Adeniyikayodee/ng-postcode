# ng-postcode-js

This is an alias. `ng-postcode-js` is the JavaScript and TypeScript library for Nigeria's NIPOST digital postcode, and it lives on npm:

```sh
npm install ng-postcode-js
```

For Python, the package is [`ng-postcode`](https://pypi.org/project/ng-postcode/):

```sh
pip install ng-postcode
```

Installing this alias installs `ng-postcode` for you. It holds no code of its own, and it exists so that the npm name leads somewhere useful on PyPI.

Source and documentation: <https://github.com/Adeniyikayodee/ng-postcode>
