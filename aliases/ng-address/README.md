# ng-address

This is an alias. The package is [`ng-address-resolver`](https://pypi.org/project/ng-address-resolver/), which resolves free-text Nigerian addresses to NIPOST digital postcodes, and which you import as `ng_address`.

```sh
pip install ng-address-resolver
```

Installing `ng-address` installs it for you. The alias holds no code of its own, and it exists so that the import name leads to the right package.

Source and documentation: <https://github.com/Adeniyikayodee/ng-postcode>
